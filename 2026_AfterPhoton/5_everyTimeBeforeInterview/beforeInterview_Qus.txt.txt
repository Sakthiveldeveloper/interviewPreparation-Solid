Advanced -----------------------------

1. Advanced Hooks & Patterns
    useMemo vs. useCallback: When to use them (and when NOT to, due to overhead) to prevent expensive re-calculations and unnecessary re-renders. 
    useReducer: When to choose it over useState for managing complex state logic with multiple sub-values. 
    useRef vs. State: Understanding that useRef persists values across renders without triggering a re-render. 
    useLayoutEffect vs. useEffect: Knowing that useLayoutEffect runs synchronously after DOM mutations but before the browser paints (essential for measuring DOM elements). 
    Custom Hooks: How to extract and share stateful logic between different components. 
2. Performance at Scale
    Memoization: Using React.memo for component-level optimization to avoid re-rendering children when props haven't changed. 
    Windowing/Virtualization: How to efficiently render massive lists (10,000+ items) using libraries like react-window or react-virtualized. 
    Code Splitting: Implementing React.lazy and Suspense to reduce initial bundle size by loading components only when needed. 
    Debouncing & Throttling: Techniques to optimize high-frequency events like window resizing or search input typing. 
3. Architecture & Ecosystem
    State Management Strategy: When to use Context API vs. dedicated libraries like Redux, Zustand, or React Query. 
    Server-Side Rendering (SSR) & Hydration: Explaining the benefits of SSR for SEO and performance, and how React "hydrates" static HTML to make it interactive. 
    Error Boundaries: Implementing componentDidCatch to prevent the entire app from crashing due to local UI errors. 
    Testing: Using React Testing Library and Jest to test component behavior rather than implementation details. 
4. Modern React (v18+)
    Automatic Batching: How React now groups multiple state updates into a single re-render for better performance. 
    Concurrent Rendering: Understanding the new concurrent features that allow React to prepare multiple versions of the UI simultaneously. 
    Transition API (useTransition): How to mark non-urgent updates as transitions to keep the UI responsive.
