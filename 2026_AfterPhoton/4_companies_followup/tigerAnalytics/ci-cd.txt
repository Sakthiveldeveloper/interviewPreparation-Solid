# 🧠 2. THEORY QUESTIONS

TOP CI/CD INTERVIEW QUESTIONS

1. What is CI/CD?
   CI/CD is a process that automates code integration, testing, and deployment.

---

2. What is Continuous Integration?
   Developers frequently merge code, and automated tests are run.

---

3. What is Continuous Delivery?
   Code is always ready to deploy but requires manual approval.

---

4. Continuous Deployment vs Delivery?
   Deployment = automatic release
   Delivery = manual approval

---

5. What is a CI/CD pipeline?
   A sequence of steps: build → test → deploy.

---

6. Why use CI/CD?

* Faster releases
* Fewer bugs
* Automation

---

7. What is Jenkins?
   An automation server used to build pipelines.

---

8. What is GitHub Actions?
   CI/CD workflows inside GitHub.

---

9. What are build artifacts?
   Compiled output (e.g., JS build files).

---

10. What is Docker?
    Container platform to run apps consistently.

---

11. What is Blue-Green deployment?
    Two environments → switch traffic safely.

---

12. What is Canary deployment?
    Release to small users first.

---

13. What is Rollback?
    Reverting to previous stable version.

---

14. What is pipeline failure?
    When any stage (build/test) fails.

---

15. What is environment (dev/stage/prod)?
    Different stages of deployment.
