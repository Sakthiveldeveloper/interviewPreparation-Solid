# 🧠 2. THEORY QUESTIONS

TOP DSA INTERVIEW QUESTIONS

1. What is DSA?
   DSA stands for Data Structures and Algorithms used to organize and process data efficiently.

2. What is Time Complexity?
   It measures how fast an algorithm runs as input grows.

3. What is Space Complexity?
   Memory used by an algorithm.

4. What is Big-O notation?
   Represents worst-case complexity.

5. Array vs Linked List?
   Array = fixed, fast access
   Linked List = dynamic, slow access

6. Stack vs Queue?
   Stack = LIFO
   Queue = FIFO

7. What is Hashing?
   Mapping data to keys for fast lookup.

8. What is Recursion?
   Function calling itself.

9. What is Binary Search?
   Search in sorted array (O(log n))

10. What is Tree?
    Hierarchical data structure.

11. What is Graph?
    Collection of nodes and edges.

12. BFS vs DFS?
    BFS = level-wise
    DFS = depth-wise

13. What is Dynamic Programming?
    Optimizing problems using stored results.

14. What is Greedy Algorithm?
    Choose best option at each step.

15. What is Backtracking?
    Try all possibilities and undo choices.
