# 🧠 2. THEORY QUESTIONS

TOP DSA INTERVIEW QUESTIONS

1. What is DSA?
   DSA stands for Data Structures and Algorithms used to organize and process data efficiently.

2. What is Time Complexity?
   It measures how fast an algorithm runs as input grows.

3. What is Space Complexity?
   Memory used by an algorithm.

4. What is Big-O notation?
   Represents worst-case complexity.

5. Array vs Linked List?
   Array = fixed, fast access
   Linked List = dynamic, slow access

6. Stack vs Queue?
   Stack = LIFO
   Queue = FIFO

7. What is Hashing?
   Mapping data to keys for fast lookup.

8. What is Recursion?
   Function calling itself.

9. What is Binary Search?
   Search in sorted array (O(log n))

10. What is Tree?
    Hierarchical data structure.

11. What is Graph?
    Collection of nodes and edges.

12. BFS vs DFS?
    BFS = level-wise
    DFS = depth-wise

13. What is Dynamic Programming?
    Optimizing problems using stored results.

14. What is Greedy Algorithm?
    Choose best option at each step.

15. What is Backtracking?
    Try all possibilities and undo choices.

# 🪟 SLIDING WINDOW — COMPLETE FLOW

---

## | 1 | 📖 **Theory Questions** |

### ❓ What is Sliding Window?

👉 A technique to **avoid nested loops** and reduce time complexity from **O(n²) → O(n)**

---

### ❓ When do we use it?

👉 When problem involves:

* Subarray / Substring
* Contiguous elements
* “Longest / Shortest / Count”

---

### ❓ Types of Sliding Window

#### 1. Fixed Window

* Window size is constant
  👉 Example: max sum of size `k`

---

#### 2. Variable Window

* Window expands & shrinks
  👉 Example: longest substring without repeating characters

---

### ❓ Key Idea

```text
Expand → Check condition → Shrink if needed
```

---

### ❓ Time Complexity

👉 O(n) (each element visited at most twice)

---

## | 2 | 💻 **Coding Questions** |

---

### 🟢 Easy: Max Sum Subarray of Size K

```javascript
function maxSum(arr, k) {
  let sum = 0;
  let max = 0;

  for (let i = 0; i < k; i++) {
    sum += arr[i];
  }

  max = sum;

  for (let i = k; i < arr.length; i++) {
    sum += arr[i] - arr[i - k];
    max = Math.max(max, sum);
  }

  return max;
}
```

---

### 🟡 Medium: Longest Substring Without Repeating Characters 🔥

```javascript
function longestSubstring(s) {
  let set = new Set();
  let left = 0;
  let max = 0;

  for (let right = 0; right < s.length; right++) {
    while (set.has(s[right])) {
      set.delete(s[left]);
      left++;
    }
    set.add(s[right]);
    max = Math.max(max, right - left + 1);
  }

  return max;
}
```

## | 4 | 🧩 **Tricky Questions** |

---

### 🔥 Trick 1: When NOT to use Sliding Window

❌ Non-contiguous problems
❌ Subsequence problems

---

### 🔥 Trick 2: Infinite Loop Bug

```javascript
while (condition) {
  // forgetting to move left pointer ❌
}
```

👉 Always move pointer!

---

### 🔥 Trick 3: Set vs Map Confusion

* Use **Set** → only uniqueness
* Use **Map** → frequency tracking

---

### 🔥 Trick 4: Off-by-One Error

👉 `right - left + 1` (very common mistake)

---

### 🔥 Trick 5: Shrinking Condition

👉 Many fail here

Wrong ❌

* Shrink too early

Correct ✅

* Shrink only when condition breaks
