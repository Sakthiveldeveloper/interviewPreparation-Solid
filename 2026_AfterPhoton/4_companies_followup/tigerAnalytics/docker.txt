# 🧠 2. THEORY QUESTIONS

TOP DOCKER INTERVIEW QUESTIONS

1. What is Docker?
   Docker is a containerization platform to package applications with dependencies.

---

2. Docker vs Virtual Machine?
   VM = full OS
   Docker = lightweight container

---

3. What is Docker Image?
   A blueprint used to create containers.

---

4. What is Container?
   Running instance of an image.

---

5. What is Dockerfile?
   A script to build Docker images.

---

6. What is Docker Compose?
   Tool to manage multiple containers.

---

7. What is Volume?
   Used to persist data outside container.

---

8. What is Port Mapping?
   Exposing container port to host.

Example: `-p 3000:3000`

---

9. What is Docker Hub?
   Public registry for images.

---

10. What is Layering?
    Each step in Dockerfile creates a layer.

---

11. What is Multi-stage build?
    Optimize image by separating build and runtime.

---

12. What is ENTRYPOINT vs CMD?
    ENTRYPOINT = fixed command
    CMD = default command

---

13. What is .dockerignore?
    Ignore files during build.

---

14. How Docker improves DevOps?
    Consistency, portability, fast deployment.

---

15. What is container orchestration?
    Managing multiple containers (Kubernetes).
