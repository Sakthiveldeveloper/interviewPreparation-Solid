☁️ AWS — Proper Categorization (Your List → Structured)
🧠 1. Compute (Where your code runs)
    👉 Core of backend execution
    AWS Lambda [must]
    AWS EC2 [must]
    AWS ECS [must]
    AWS EKS [good]
    💡 Interview tip:
    If they ask “where does your app run?” → start here.
💾 2. Storage (Where data/files are stored)
    S3 [must]
    ECR (Elastic Container Registry) [good]
    💡 S3 = files
    💡 ECR = Docker images
🗄️ 3. Database (Structured & NoSQL data)
    RDS / Aurora [must]
    DynamoDB [must]
    💡 RDS → SQL
    💡 DynamoDB → NoSQL (high scale)
🌐 4. Networking & CDN (How users reach your app)
    VPC / Subnets [must]
    Route 53 [good]
    CloudFront [good]
    ACM (SSL Certificates) [good]
💡 This is where many people get weak → very important for interviews
🔐 5. Security & Access Control
    IAM (Roles & Policies) [must]
    💡 IAM is one of the most asked topics
📡 6. Integration & Messaging (Service communication)
    SQS [must]
    SNS [must]
    EventBridge [must]
    💡
    SQS → queue
    SNS → pub/sub
    EventBridge → event routing

🌍 7. API Layer
    API Gateway [must]
    💡 Used with Lambda → very common architecture
📊 8. Monitoring & Logging
    CloudWatch [must]
    💡 Logs + metrics + alerts
⚙️ 9. DevOps & Deployment (AWS side)
    AWS CodePipeline [good]
    AWS CodeDeploy [good]
🚀 10. Advanced / Optimization Topics
    Lambda cold start optimization [good]
    AWS cost optimization [good]
