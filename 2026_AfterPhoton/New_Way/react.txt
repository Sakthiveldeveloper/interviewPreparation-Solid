For your background (MERN + Module Federation experience), I'd pay extra attention to:

1. React Hooks
2. React Internals (Virtual DOM, Reconciliation, Fiber)
3. Redux Toolkit
4. Performance Optimization
5. React Design Patterns
6. React Architecture
7. Module Federation
8. TypeScript with React

Those topics are what usually separate a 6–10 LPA developer from a 12–20+ LPA React developer in interviews.
