    🧠 1. What is S3 (Simple Storage Service)?

    👉 Amazon S3 = Cloud Storage (like Google Drive, but for apps)

    You can store:
    Images 🖼️
    Videos 🎥
    PDFs 📄
    JSON / backups 💾
    Static websites 🌐

    📌 Think:

    “S3 is a bucket where I can store unlimited files safely.”

    🎯 2. Why S3 is Needed?
    Real-world use cases:
    Upload profile images in your app
    Store large files instead of DB
    Backup databases
    Host frontend apps (React/Vue)
    Store logs / analytics data

    💡 Example (MERN):

    User uploads image → store in S3 → save URL in MongoDB
    🏗️ 3. Core Concepts (VERY IMPORTANT)
    🪣 Bucket
    Like a folder/container
    Must be globally unique name
    📦 Object
    File stored in S3 (image, video, etc.)
    🔐 Permissions
    Public / Private access
    Controlled using IAM policies
    🌍 Region
    Where your data is stored (e.g., ap-south-1 for India)
    🚀 4. How to Start S3 (Step-by-Step)
    Step 1: Create Bucket
    Go to AWS Console
    Open S3
    Click Create Bucket
    Enter:
    Bucket name (unique)
    Region (choose India: ap-south-1)
    Step 2: Upload File
    Open your bucket
    Click Upload
    Add file → Upload
    Step 3: Access File
    By default: ❌ Private
    To make public:
    Disable “Block Public Access”
    Add permission
    Step 4: Get URL
    https://your-bucket-name.s3.amazonaws.com/file.jpg
    💻 5. How to Use S3 in Node.js (MERN)

    Install SDK:

    npm install @aws-sdk/client-s3

    Basic upload example:

    import { S3Client, PutObjectCommand } from "@aws-sdk/client-s3";
    import fs from "fs";

    const client = new S3Client({
    region: "ap-south-1",
    credentials: {
        accessKeyId: "YOUR_KEY",
        secretAccessKey: "YOUR_SECRET"
    }
    });

    const upload = async () => {
    const fileContent = fs.readFileSync("image.jpg");

    const command = new PutObjectCommand({
        Bucket: "your-bucket-name",
        Key: "image.jpg",
        Body: fileContent
    });

    await client.send(command);
    };

    upload();
    🧠 6. When to Use S3 vs NOT
    ✅ Use S3 when:
    Files are large
    Need scalability
    Need CDN (CloudFront)
    Static hosting
    ❌ Avoid when:
    Need relational queries → use DB
    Need real-time updates → use DB / cache
    ⚡ 7. S3 + Other AWS Services (Important for Interviews)
    S3 + CloudFront → Fast CDN
    S3 + Lambda → Auto processing (image resize)
    S3 + EC2 → Store files
    S3 + IAM → Security

What is lifecycle policy?

What is pre-signed URL?

S3 + CloudFront?

💻 2. CODING (Node.js + MERN Style)
🔹 Install
npm install @aws-sdk/client-s3 multer multer-s3
🔹 Basic Upload (Backend)
import { S3Client, PutObjectCommand } from "@aws-sdk/client-s3";

const s3 = new S3Client({
  region: "ap-south-1",
  credentials: {
    accessKeyId: process.env.ACCESS_KEY,
    secretAccessKey: process.env.SECRET_KEY
  }
});

export const uploadFile = async (file) => {
  const params = {
    Bucket: "your-bucket-name",
    Key: file.originalname,
    Body: file.buffer,
    ContentType: file.mimetype
  };

  await s3.send(new PutObjectCommand(params));

  return `https://${params.Bucket}.s3.amazonaws.com/${params.Key}`;
};
🔹 Express API
import express from "express";
import multer from "multer";
import { uploadFile } from "./s3.js";

const app = express();
const upload = multer();

app.post("/upload", upload.single("file"), async (req, res) => {
  try {
    const url = await uploadFile(req.file);
    res.json({ url });
  } catch (err) {
    res.status(500).json({ error: err.message });
  }
});
