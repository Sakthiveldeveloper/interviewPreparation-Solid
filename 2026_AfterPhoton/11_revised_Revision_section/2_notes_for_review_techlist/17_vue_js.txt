    🔹 1. What is Vue.js?

    Answer:
    Vue.js is a progressive JavaScript framework used to build user interfaces. It focuses on simplicity, reactivity, and component-based architecture.

    🔹 2. What is reactivity in Vue?

    Answer:
    Reactivity means when data changes, the UI automatically updates. Vue tracks dependencies and updates only affected parts.

    🔹 3. How Vue reactivity works internally?

    Answer:
    Vue 3 uses Proxy to track changes. It uses:

    track() → collects dependencies
    trigger() → updates components
    🔹 4. Difference between ref() and reactive()

    Answer:

    ref() → used for primitive values
    reactive() → used for objects
    ref uses .value, reactive does not
    🔹 5. Can reactive hold primitive values?

    Answer:
    No, reactive works only with objects.

    🔹 6. What is computed?

    Answer:
    Computed is a derived state that is cached and recalculated only when dependencies change.

    🔹 7. computed vs methods

    Answer:

    computed → cached
    methods → runs every time
    🔹 8. computed vs watch

    Answer:

    computed → for derived values
    watch → for side effects
    🔹 9. watch vs watchEffect

    Answer:

    watch → tracks specific value
    watchEffect → auto tracks dependencies
    🔹 10. What is v-model?

    Answer:
    v-model provides two-way data binding between input and state.

    🔹 11. How v-model works internally?

    Answer:

    prop: modelValue
    event: update:modelValue
    🔹 12. What are components?

    Answer:
    Reusable UI blocks with template, logic, and styles.

    🔹 13. What are props?

    Answer:
    Props are used to pass data from parent to child.

    🔹 14. Why props should not be mutated?

    Answer:
    Because Vue follows one-way data flow. Mutating props causes unpredictable behavior.

    🔹 15. What are emits?

    Answer:
    Used to send data from child to parent.

    🔹 16. What are slots?

    Answer:
    Slots allow passing HTML content into components.

    🔹 17. Types of slots

    Answer:

    Default
    Named
    Scoped
    🔹 18. What is Composition API?

    Answer:
    A modern API that allows organizing logic using functions for better reusability.

    🔹 19. Why Composition API?

    Answer:

    Better code organization
    Reusability (composables)
    Scalable
    🔹 20. What is setup()?

    Answer:
    The entry point of Composition API where reactive data and logic are defined.

    🔹 21. Lifecycle hooks in Vue

    Answer:
    mounted, updated, unmounted, etc.

    🔹 22. mounted vs created

    Answer:

    created → data ready
    mounted → DOM ready
    🔹 23. What is Vue Router?

    Answer:
    Library used for navigation between pages in Vue apps.

    🔹 24. What are route guards?

    Answer:
    Functions that control navigation (authentication, authorization).

    🔹 25. What is Pinia?

    Answer:
    Modern state management library for Vue.

    🔹 26. Pinia vs Vuex

    Answer:

    Pinia → simple, no mutations
    Vuex → complex, uses mutations
    🔹 27. What is Virtual DOM?

    Answer:
    A lightweight copy of real DOM used to optimize updates.

    🔹 28. What is nextTick()?

    Answer:
    Executes code after DOM updates.

    🔹 29. What is v-if vs v-show?

    Answer:

    v-if → adds/removes DOM
    v-show → toggles visibility
    🔹 30. How to optimize performance in Vue?

    Answer:

    Use computed
    Avoid unnecessary watchers
    Lazy load components
    Use v-once
