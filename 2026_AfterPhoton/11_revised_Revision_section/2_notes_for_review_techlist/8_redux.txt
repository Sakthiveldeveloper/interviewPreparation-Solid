✅ Redux Theory – Q&A (Interview Revision Notes)
    🔹 Core Fundamentals
    1. What is Redux?
        Redux is a state management library used to manage and centralize application state in a predictable way.
    2. Why use Redux?
        Centralized state
        Predictable state updates
        Easier debugging
        Better for large-scale applications
    3. What is State in Redux?
        State is a single JavaScript object that holds the entire application data.
    4. What is a Store?
        Store is the central place where the application state is stored and managed.
    5. What is an Action?
        An action is an object that describes what happened. It must have a type property.
    6. What is a Reducer?
        A reducer is a pure function that takes the current state and an action, and returns a new state.

    🔹 Core Flow
    7. Explain Redux Data Flow
        User triggers action
        Action is dispatched
        Reducer processes action
        Store updates state
        UI re-renders
    👉 This is called unidirectional data flow
    🔹 Key Concepts
    8. What is Dispatch?
        Dispatch is a method used to send actions to the Redux store.
    9. What is combineReducers?
        Used to combine multiple reducers into one root reducer.
    10. What is Middleware?
        Middleware is used to intercept actions before they reach reducers (for logging, async calls, etc.)
    🔹 Redux Toolkit (Important 🔥)
    11. What is Redux Toolkit (RTK)?
        Redux Toolkit is the official, recommended way to write Redux logic with less boilerplate.
    12. Why use Redux Toolkit?
        Less code
        Built-in best practices
        Easier state updates
        Includes Redux Thunk by default
    13. What is createSlice?
        A function that creates reducer + actions together.
    14. What is createStore vs configureStore?
        createStore → old way
        configureStore → modern RTK way (recommended)
    🔹 Async Handling
    15. What is Redux Thunk?
        Middleware that allows writing async logic using functions instead of plain objects.
    16. What is Redux Saga?
        Middleware that uses generator functions to handle complex async flows.
    17. Difference between Thunk and Saga?
        Feature Thunk Saga Style Simple Complex Syntax Functions Generators Learning Easy Hard Use CaseBasic async Complex workflows
    🔹 React Integration
    18. What is useSelector?
        Hook used to read data from Redux store.
    19. What is useDispatch?
        Hook used to dispatch actions.
    20. What is Provider?
        Component that makes Redux store available to the entire React app.

    🔹 Advanced Concepts
    21. What is Normalization?
        Storing data in a structured way to avoid duplication.
    22. What is Immutable Update?
        State should not be mutated directly; always return a new state.
    23. What is Redux DevTools?
        A debugging tool to track state changes and actions.
    🔹 Best Practices
    24. When should you use Redux?
        Large applications
        Shared state across components
        Complex state logic
    25. When should you avoid Redux?
        Small apps
        Simple state (use useState/useContext instead)
    🔥 Pro Tip (Very Important for Interview)
    If they ask Redux:
    👉 Start like this:

    “Redux is used for global state management where multiple components need access to shared data.”

    👉 Then add:
        Flow (Action → Reducer → Store)
        Example (login state, cart, dashboard data)

    Reducer → decision maker

        ↓
    Create Slice

        ↓

        ↓
    Provider gives store to app
        ↓
    useDispatch → send action
    useSelector → read state
    ---------------------------------------------
    1. Install Redux Toolkit
        npm install @reduxjs/toolkit react-redux
    2. Create Slice
        import { createSlice } from "@reduxjs/toolkit";

        const counterSlice = createSlice({
        name: "counter",

        initialState: {
            count: 0
        },

        reducers: {
            increment: (state) => {
            state.count += 1;
            }
        }
        });

        export const { increment } = counterSlice.actions;

        export default counterSlice.reducer;
    3. Create Store
        import { configureStore } from "@reduxjs/toolkit";
        import counterReducer from "./counterSlice";

        export const store = configureStore({
        reducer: {
            counter: counterReducer
        }
        })
    4. Wrap App with Provider
        import { Provider } from "react-redux";
        import { store } from "./store";

        <Provider store={store}>
        <App />
        </Provider>
    5. Use useDispatch + useSelector
        import { useDispatch, useSelector } from "react-redux";
        import { increment } from "./counterSlice";
        export default function App() {
        const dispatch = useDispatch();
        const count = useSelector(
            (state) => state.counter.count
        );
        return (
            <div>
            <h1>{count}</h1>
            <button
                onClick={() => dispatch(increment())}
            >
                Increment
            </button>
            </div>
        )
        }
