🎯 AWS Lambda Interview Questions (with Answers)
🧠 Basic Level (Must Know)
1. What is AWS Lambda?

👉 Lambda is a serverless compute service where you run code without managing servers. It executes code in response to events and scales automatically.

2. What is serverless?

👉 Serverless means:

No server management
Auto scaling
Pay only for execution time
3. What languages does Lambda support?

👉 Node.js, Python, Java, Go, .NET

4. What is a Lambda function?

👉 A function is the unit of execution in Lambda. It contains your code + configuration.

5. What triggers Lambda?

👉 Common triggers:

API Gateway (HTTP calls)
S3 (file upload)
DynamoDB streams
SQS / SNS
EventBridge (cron jobs)
⚡ Intermediate Level (Very Important)
6. What is cold start?

👉 When Lambda runs for the first time (or after inactivity), it takes extra time to initialize.

7. How to reduce cold start?

👉

Use smaller packages
Choose faster runtime (Node.js)
Use Provisioned Concurrency
8. What is the max execution time?

👉 15 minutes

9. What is concurrency in Lambda?

👉 Number of requests Lambda can handle at the same time.

Types:

Reserved concurrency
Provisioned concurrency
10. What is the difference between Lambda and EC2?
Feature	Lambda	EC2
Server	No	Yes
Scaling	Auto	Manual
Billing	Per request	Per hour
Use case	Short tasks	Long-running apps
11. What is API Gateway?

👉 Amazon API Gateway is used to expose Lambda as an HTTP API.

12. What is the event object?

👉 Input data passed to Lambda (like request body, headers, etc.)

13. What is context object?

👉 Contains runtime info like:

request ID
execution time remaining
🔐 Advanced Level (High Impact)
14. What is IAM role in Lambda?

👉 AWS Identity and Access Management role gives permission to Lambda to access other AWS services.

Example:

Access S3
Read DynamoDB
15. What is Lambda Layer?

👉 Used to share common code (libraries) across multiple Lambda functions.

16. What is DLQ (Dead Letter Queue)?

👉 Stores failed events for debugging.

17. What is Lambda destination?

👉 Defines what happens after execution:

Success → send to another service
Failure → send to SQS/SNS
18. How does Lambda scale?

👉 Automatically creates multiple instances based on incoming requests.

19. What is stateless in Lambda?

👉 Each execution is independent
(No memory of previous execution)

20. Can we connect Lambda to VPC?

👉 Yes, for accessing private resources (like RDS)

🔥 Scenario-Based Questions (VERY IMPORTANT)
21. How would you build a REST API using Lambda?

👉 Answer:

Use API Gateway for routing
Lambda for business logic
Database (DynamoDB / MongoDB)
22. How to process file uploads using Lambda?

👉 Answer:

Upload file to S3
Trigger Lambda
Process file (resize, parse, etc.)
23. How to handle high traffic?

👉 Answer:

Lambda auto scales
Use reserved concurrency if needed
Optimize function performance
24. How to secure Lambda?

👉 Answer:

Use IAM roles
Use API Gateway authentication (JWT, Cognito)
Avoid hardcoding secrets
25. How to debug Lambda?

👉 Answer:

Use CloudWatch Logs
Use X-Ray for tracing
