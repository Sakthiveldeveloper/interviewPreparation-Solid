2.Theory Questions
   Here is a concise summary of the 25 key Node.js topics we covered, organized for quick revision.
   Core Fundamentals
      1. What is Node.js? A cross-platform, open-source JavaScript runtime built on Chrome's V8 engine that executes JS code outside the browser.
      2. What is "Non-Blocking"? The ability of Node.js to start an I/O task and move to the next one without waiting for the first to finish.
      3. What is Event-Driven Architecture? A design where the flow is determined by events (clicks, data arrivals). The "Event Loop" listens for these signals to trigger functions.
      4. What is the Event Loop? The mechanism that allows Node.js to perform non-blocking I/O operations by offloading tasks to the system kernel whenever possible.
      5. What are Callbacks? Functions passed as arguments to other functions, executed once an asynchronous task completes (usually following the "error-first" pattern).
      6. What are Promises? Objects representing the eventual completion (or failure) of an async operation, providing .then() and .catch() methods.
      7. What is Async/Await? Syntactic sugar built on Promises that allows asynchronous code to be written and read like synchronous code using try/catch.

   Frameworks & APIs

      1. What is Express.js? A minimalist, flexible web framework for Node.js that provides robust features for web and mobile applications (routing, middleware).
      2. What is Fastify? A high-performance framework focused on low overhead and powerful plugin architecture, often 2x faster than Express.
      3. What is a REST API? An architectural style for networked applications using HTTP methods (GET, POST, etc.) to manipulate resources at specific URLs.
      4. What is GraphQL? A query language for APIs that allows clients to request exactly the data they need, preventing over-fetching.
      5. What are HTTP Methods? Standard "verbs" (GET, POST, PUT, DELETE, PATCH) that define the action a client wants the server to perform.
      6. What is JSON? (JavaScript Object Notation) A lightweight, text-based data format used to exchange data between a server and a web application.

   Architecture & Data

      1. What is Middleware? Functions that have access to the Request and Response objects, sitting "in the middle" to perform tasks like logging or auth.
      2. What are the Types of Middleware? Application-level, Router-level, Built-in, Error-handling, and Third-party.
      3. What is an ORM? (Object-Relational Mapping) A tool like Prisma or Sequelize that lets you query a database using JS objects instead of raw SQL.
      4. What are Environment Variables? External variables (stored in .env files) used to hide sensitive data like API keys and DB passwords from the source code.
      5. How do you structure a Node project? By using Layered Architecture (Folders for: Routes, Controllers, Services, Models, and Middlewares).
      6. How do you handle 1 Lakh+ records? By using Pagination (chunks), Streams (processing bit-by-bit), or Database Cursors.

   Security & Production

      1. What is JWT? (JSON Web Token) A stateless way to handle authentication by passing a signed token between client and server.
      2. What is Validation? The process of checking if user input is correct/safe before processing (using libraries like Zod or Joi).
      3. What is Rate Limiting? Restricting the number of requests a user can make in a certain timeframe to prevent DDoS and brute-force attacks.
      4. What is Logging? Recording app events/errors (using Winston or Pino) to help debug issues in production.
      5. How do you handle Concurrency? Through the Event Loop, Worker Threads (for CPU tasks), or Clustering (multiple processes).
      6. How do you handle Production issues? By using APM tools (Datadog), Error Tracking (Sentry), and Process Managers (PM2) for auto-restarts.
