# 🧠 2. THEORY QUESTIONS

    TOP SYSTEM DESIGN INTERVIEW QUESTIONS

    1. What is System Design?
    System design is the process of designing scalable, reliable, and efficient systems.

    2. What are Functional Requirements?
    They define what the system should do.

    3. What are Non-Functional Requirements?
    They define performance, scalability, and reliability.

    4. What is Scalability?
    Ability of a system to handle increasing load.

    5. Vertical vs Horizontal Scaling?
    Vertical = increase server power
    Horizontal = add more servers

    6. What is Load Balancer?
    Distributes traffic across multiple servers.

    7. What is Caching?
    Storing frequently accessed data for faster response.

    8. What is CDN?
    Content Delivery Network to serve content faster.

    9. SQL vs NoSQL?
    SQL = structured data
    NoSQL = flexible, scalable

    10. What is Sharding?
        Splitting database across multiple servers.

    11. What is Replication?
        Copying data across servers for availability.

    12. What is API Gateway?
        Entry point for all client requests.

    13. What is Rate Limiting?
        Restricting number of requests per user.

    14. What is Microservices?
        Small independent services communicating via APIs.

    15. Monolith vs Microservices?
        Monolith = single app
        Microservices = distributed services

    16. What is Event-driven architecture?
        System reacts to events asynchronously.

    17. What is Message Queue?
        Used for async communication.

    18. What is CAP Theorem?
        Consistency, Availability, Partition tolerance.

    19. What is Latency?
        Time taken to respond.

    20. What is Throughput?
        Number of requests handled per second.
