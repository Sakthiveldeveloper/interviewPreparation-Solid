2.Theory Questions
Here is a summary of the core React concepts we've covered, formatted for quick reference:
What is React?
A JavaScript library for building user interfaces based on UI components. It uses a Virtual DOM to make updates fast and efficient.
What is the Virtual DOM?
A lightweight copy of the real DOM kept in memory. React compares this copy to the real DOM (diffing) and only updates the parts that changed, improving performance.
What is a Component?
The building block of a React app. It is a self-contained, reusable piece of code (usually a function) that returns JSX to describe a part of the UI.
What is JSX?
A syntax extension that looks like HTML but lives in JavaScript. It makes writing component structures more visual and is compiled into standard JavaScript objects.
What are Props vs. State?

* Props: Read-only data passed from a parent to a child (external).
* State: Data managed locally within a component that can change over time (internal).

What is a Re-render?
The process where React calls a component function again to update the UI. It is triggered by changes in state, props, or the parent component.
What are Hooks?
Functions that let you "hook into" React features in functional components. Examples include useState for data and useEffect for side effects.
What is the useEffect Dependency Array?
An array passed as the second argument to useEffect. It tells React to only re-run the effect when specific values inside that array change.
Controlled vs. Uncontrolled Components?

* Controlled: React state handles the form data (the "React way").
* Uncontrolled: The DOM handles the form data, accessed via useRef.

What is the key prop?
A unique string used in lists to help React identify which items changed, were added, or were removed, preventing rendering bugs.
What is Lifting State Up?
Moving state to the closest common parent component so multiple child components can share and stay in sync with the same data.
What is Conditional Rendering?
Showing different UI elements based on logic, typically using if statements, ternary operators (? :), or logical AND (&&).
What is a Fragment?
A syntax (<>...</>) that lets you group multiple elements without adding an extra, unnecessary <div> to the real HTML DOM.
useMemo vs. useCallback?

* useMemo: Caches the result of an expensive calculation.
* useCallback: Caches the function definition itself to prevent unnecessary child re-renders.

What is React.memo?
A tool that wraps a component to prevent it from re-rendering unless its props actually change.
What is the Context API?
A way to share data globally across the component tree without "prop drilling" (passing data through every level).
