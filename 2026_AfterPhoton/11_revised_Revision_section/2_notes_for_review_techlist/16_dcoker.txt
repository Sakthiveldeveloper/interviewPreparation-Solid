🧠 4. SCENARIO QUESTIONS (INTERVIEW GOLD 🔥)
    🔹 Scenario 1
        👉 Your app works locally but not in production Docker
        → Check ports, env variables, network
    🔹 Scenario 2
        👉 Data lost after container restart
        → Use volumes
    🔹 Scenario 3
        👉 App size too large
        → Use multi-stage build
    🔹 Scenario 4
        👉 Multiple services (Node + DB)
        → Use Docker Compose
    🔹 Scenario 5
        👉 Need to scale containers
        → Use orchestration (basic idea: Kubernetes)
