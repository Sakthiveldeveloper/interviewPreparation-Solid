# 2️⃣ Maximum Sum Subarray of Size K — Complete Interview Notes

---

# Problem Statement

Given:

* an array of numbers
* integer `k`

Find the maximum sum of any contiguous subarray of size `k`.

---

# Example

```js id="jlwm50"
arr = [2,1,5,1,3,2]
k = 3
```

Subarrays:

```txt id="’wini51"

[1,5,1] = 7
[5,1,3] = 9
[1,3,2] = 6
```

Output:

```txt id="’wini52"
9
```

# Why Sliding Window?

Every next window overlaps previous window.

Example:

```txt id="’wini57"
[2,1,5]
[1,5,1]
```

Instead of recalculating full sum:

* remove left
* add right

Efficient.

---

# Why NOT Other Patterns?

| Pattern       | Why Not           |
| ------------- | ----------------- |
| Two Pointers  | no pair searching |
| Binary Search | no searching      |
| DFS/BFS       | no graph/tree     |
| DP            | unnecessary       |

Sliding Window is the perfect fit.

---

# Step 3 — Brute Force Approach

## Thinking

For every index:

* calculate next `k` elements sum
* track maximum

---

# Brute Force Code

```js id="’wini58"
function maxSumBruteForce(arr, k) {

    let maxSum = 0;

    for (let i = 0; i <= arr.length - k; i++) {

        let sum = 0;

        for (let j = i; j < i + k; j++) {

            sum += arr[j];
        }

        maxSum = Math.max(maxSum, sum);
    }

    return maxSum;
}
```

# Final Optimized Code

```js id="’wini73"
function maxSumSubarray(arr, k) {

    let windowSum = 0;
    let maxSum = 0;
    let left = 0;

    for (let right = 0; right < arr.length; right++) {

        // add right element
        windowSum += arr[right];

        // window size reached
        if (right >= k - 1) {

            // update maximum
            maxSum = Math.max(maxSum, windowSum);

            // remove left element
            windowSum -= arr[left];

            // move left pointer
            left++;
        }
    }

    return maxSum;
}
```
