# 📌 Problem

Given a string `s`, return:

```txt
true  -> palindrome
false -> not palindrome
```

Palindrome means:

* same forward
* same backward

Example:

```js
"madam"    -> true
"racecar"  -> true
"hello"    -> false
```

---

# 🧠 Brute Force Idea

Reverse string and compare.

```js
str === str.split('').reverse().join('')
```

But interviewers want:

* optimized
* two pointer approach

---

# ✅ Two Pointer Idea

Use:

* left pointer
* right pointer

Compare both sides.

---

# Visualization

```txt
m a d a m
L       R
```

Compare:

```txt
m === m ✅
```

Move:

```txt
left++
right--
```

---

Next:

```txt
m a d a m
  L   R
```

Compare:

```txt
a === a ✅
```

Move again.

Now:

```txt
L == R
```

DONE.

---

# 🚀 Algorithm

```txt
1. left = 0
2. right = last index

3. while left < right

4. compare chars

5. if different
      return false

6. move both pointers

7. return true
```

---

# ✅ Code (JavaScript)

```javascript
function isPalindrome(str) {

    let left = 0;
    let right = str.length - 1;

    while (left < right) {

        if (str[left] !== str[right]) {
            return false;
        }

        left++;
        right--;
    }

    return true;
}
```
