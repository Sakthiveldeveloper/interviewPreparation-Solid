# What is Dynamic Programming?

Dynamic Programming (DP) is a problem-solving technique where:

```txt
solve smaller problems
store answers
reuse them later
```

instead of recalculating again and again.

---

# Why Use DP?

Convert:

```txt
O(2ⁿ) → O(n)
```

or

```txt
O(n²)
```

by avoiding repeated work.

---

# Main Idea

```txt
Overlapping Subproblems
+
Optimal Substructure
```

---

# Real Meaning

Instead of:

```txt
solve same thing many times
```

We:

```txt
save answer once
reuse later
```

---

# Example

## Fibonacci

Without DP:

```txt
fib(5)
→ fib(4) + fib(3)

fib(4)
→ fib(3) + fib(2)

fib(3)
→ repeated again and again
```

Huge repeated work 😵

---

# DP Solution

Store answers:

```js
memo[3] = 2
```

Next time:

```txt
reuse directly
```

---

# Template

```js
function dp(n, memo = {}) {

    if (n in memo) {
        return memo[n];
    }

    if (base condition) {
        return value;
    }

    memo[n] = recurrence relation;

    return memo[n];
}
```

---

# Fibonacci Example

```js
function fib(n, memo = {}) {

    if (n in memo) {
        return memo[n];
    }

    if (n <= 2) {
        return 1;
    }

    memo[n] =
        fib(n - 1, memo) +
        fib(n - 2, memo);

    return memo[n];
}
```

# 2️⃣ Tabulation (Bottom Up)

## Flow

```txt
Start from smallest problem
Build answer step by step
```

---

# Template

```js
function dp(n) {

    let table = new Array(n + 1).fill(0);

    table[0] = baseValue;

    for (let i = 0; i <= n; i++) {

        // build next states
    }

    return table[n];
}
```

---

# Fibonacci Tabulation

```js
function fib(n) {

    let dp = [0, 1, 1];

    for (let i = 3; i <= n; i++) {

        dp[i] = dp[i - 1] + dp[i - 2];
    }

    return dp[n];
}
```

# 1️⃣ Climbing Stairs Pattern

## Idea

```txt
current step =
previous 1 step +
previous 2 step
```

Formula:

dp[i]=dp[i-1]+dp[i-2]

---

# 2️⃣ House Robber Pattern

## Idea

Choice:

```txt
rob current
OR
skip current
```

Formula:

dp[i]=\max(dp[i-1],dp[i-2]+nums[i])

---

# 3️⃣ Coin Change Pattern

## Idea

```txt
minimum coins needed
```

Formula:

dp[i]=\min(dp[i],dp[i-coin]+1)
