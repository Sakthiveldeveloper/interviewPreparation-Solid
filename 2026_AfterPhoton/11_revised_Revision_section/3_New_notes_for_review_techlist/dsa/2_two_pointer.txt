# What is Two Pointer?

Two Pointer is a **DSA pattern** where:

```txt
two variables move through data
```

to solve problems efficiently.

Instead of:

```js
for(i){
   for(j){

   }
}
```

We use:

```txt
left pointer
right pointer
```

to reduce complexity.

---

# Why Use Two Pointer?

Convert:

```txt
O(n²) → O(n)
```

Optimize brute force solutions.

---

# Core Idea

Pointers move intelligently.

Example:

```txt
1 2 3 4 5
L       R
```

Move:

* left++
* right--

depending on condition.

# Opposite Pointer Template

```js
function twoPointer(arr) {

    let left = 0;
    let right = arr.length - 1;

    while (left < right) {

        let value = arr[left] + arr[right];

        if (condition) {

            left++;

        } else {

            right--;
        }
    }
}
```

# Fast & Slow Template

```js
function fastSlow(arr) {

    let slow = 0;

    for (let fast = 0; fast < arr.length; fast++) {

        if (condition) {

            arr[slow] = arr[fast];

            slow++;
        }
    }
}
```

# Fast & Slow Flow

# Partition Template

```js
function partition(arr) {

    let left = 0;

    for (let right = 0; right < arr.length; right++) {

        if (condition) {

            [arr[left], arr[right]] =
            [arr[right], arr[left]];

            left++;
        }
    }
}
```
