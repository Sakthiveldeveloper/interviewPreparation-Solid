1.1 Definitions 
    DATA STRUCTURES & ALGORITHMS (DSA) — DEFINITIONS

    --------------------------------------------------
    0. 🔥 Problem-Solving Patterns
    --------------------------------------------------

    Definition:
    Problem-solving patterns are common approaches used to solve different types of problems efficiently by recognizing similar structures.

    Purpose:
    Instead of solving every problem from scratch, patterns help quickly identify the right approach.

    Examples:
    Sliding Window, Two Pointer, DFS/BFS, Greedy, etc.

    🪟 1. Sliding Window
    Definition:
    Used to solve subarray/substring problems by maintaining a moving window.

    When to use:
    - Subarray / substring
    - Continuous elements
    - Longest / shortest

    Questions:
    1. Maximum Sum Subarray of Size K
    2. Longest Substring Without Repeating Characters
    3. Minimum Window Substring
    4. Longest Repeating Character Replacement

    👯 2. Two Pointer
    Definition:
    Use two pointers to reduce time complexity (start & end).

    When to use:
    - Sorted arrays
    - Pair problems

    Questions:
    5. Two Sum II (sorted)
    6. Container With Most Water
    7. 3Sum

    🐢 3. Fast & Slow Pointer
    Definition:
    Two pointers move at different speeds.

    When to use:
    - Linked list cycle detection

    Questions:
    8. Linked List Cycle
    9. Find Middle of Linked List

    🔍 4. Binary Search Pattern
    Definition:
    Search by dividing search space.

    When to use:
    - Sorted data
    - Monotonic condition

    Questions:
    10. Binary Search
    11. Search in Rotated Sorted Array
    12. Find Peak Element
    13. Koko Eating Bananas

    🌳 5. DFS / BFS
    Definition:
    Traversal techniques for trees & graphs.

    When to use:
    - Tree/graph traversal

    Questions:
    14. Maximum Depth of Binary Tree
    15. Level Order Traversal
    16. Number of Islands
    17. Clone Graph

    🔁 6. Backtracking
    Definition:
    Try all possibilities, backtrack on failure.

    When to use:
    - Permutations / combinations

    Questions:
    18. Subsets
    19. Permutations
    20. Combination Sum

    💰 7. Greedy
    Definition:
    Take best choice at each step.

    When to use:
    - Optimization problems

    Questions:
    21. Jump Game
    22. Gas Station
    23. Activity Selection

    📈 8. Kadane’s Algorithm
    Definition:
    Find maximum subarray sum in O(n).

    When to use:
    - Maximum sum problems

    Questions:
    24. Maximum Subarray
    25. Maximum Circular Subarray

    📊 9. Monotonic Stack
    Definition:
    Stack that maintains increasing/decreasing order.

    When to use:
    - Next greater/smaller element

    Questions:
    26. Next Greater Element
    27. Daily Temperatures
    28. Largest Rectangle in Histogram

    🧮 10. Hashing
    Definition:
    Use HashMap/Set for fast lookup.

    When to use:
    - Frequency / duplicates

    Questions:
    29. Two Sum
    30. Longest Consecutive Sequence
    --------------------------------------------------
    1. Fundamentals
    --------------------------------------------------

    Definition:
    Fundamentals are the basic concepts that help you understand how algorithms work and how to analyze their performance.

    Purpose:
    They guide how to think, optimize, and evaluate solutions.

    Includes:
    - Complexity Analysis
    - Recursion
    - Problem-Solving Techniques

    --------------------------------------------------
    1.1 Complexity Analysis
    --------------------------------------------------

    Definition:
    Complexity analysis measures how the performance (time and memory) of an algorithm changes with input size.

    Types:
    - Time Complexity → Execution time
    - Space Complexity → Memory usage

    Notations:
    - Big O (O) → Worst case
    - Omega (Ω) → Best case
    - Theta (Θ) → Average case

    --------------------------------------------------
    1.2 Recursion
    --------------------------------------------------

    Definition:
    Recursion is a technique where a function calls itself to solve smaller parts of a problem.

    Key Concepts:
    - Base Case → stopping condition
    - Recursive Case → repeated call

    Used in:
    Trees, backtracking, divide & conquer

    --------------------------------------------------
    1.3 Problem-Solving Techniques
    --------------------------------------------------

    Definition:
    General strategies used to approach and solve problems efficiently.

    Types:
    - Brute Force → Try all possibilities
    - Greedy → Choose best option at each step
    - Divide & Conquer → Break problem into parts
    - Dynamic Programming → Store results
    - Backtracking → Explore all solutions

    --------------------------------------------------
    2. Linear Data Structures
    --------------------------------------------------

    Definition:
    Linear data structures store elements in a sequential order where each element has a single predecessor and successor.

    Examples:
    - Array
    - Linked List
    - Stack
    - Queue

    Characteristics:
    - Easy traversal
    - Single level structure

    --------------------------------------------------
    2.1 Arrays
    --------------------------------------------------

    Definition:
    A collection of elements stored in contiguous memory locations.

    Used for:
    Fast access and iteration

    --------------------------------------------------
    2.2 Strings
    --------------------------------------------------

    Definition:
    A sequence of characters treated as a data structure similar to arrays.

    Used for:
    Text processing problems

    --------------------------------------------------
    2.3 Linked Lists
    --------------------------------------------------

    Definition:
    A data structure where elements (nodes) are connected using pointers.

    Types:
    Singly, Doubly, Circular

    --------------------------------------------------
    2.4 Stack
    --------------------------------------------------

    Definition:
    A linear data structure that follows LIFO (Last In First Out).

    Used in:
    Recursion, expression evaluation

    --------------------------------------------------
    2.5 Queue
    --------------------------------------------------

    Definition:
    A linear data structure that follows FIFO (First In First Out).

    Used in:
    Scheduling, BFS traversal

    --------------------------------------------------
    3. Non-Linear Data Structures
    --------------------------------------------------

    Definition:
    Data structures where elements are arranged in hierarchical or network-based relationships.

    Examples:
    - Trees
    - Graphs

    --------------------------------------------------
    3.1 Trees
    --------------------------------------------------

    Definition:
    A hierarchical structure consisting of nodes connected in parent-child relationships.

    Used in:
    Search, hierarchical data

    --------------------------------------------------
    3.2 Graphs
    --------------------------------------------------

    Definition:
    A collection of nodes connected by edges representing relationships.

    Used in:
    Networks, shortest path problems

    --------------------------------------------------
    3.3 Hashing
    --------------------------------------------------

    Definition:
    A technique to map data to fixed-size values using a hash function for fast lookup.

    Examples:
    HashMap, HashSet

    --------------------------------------------------
    4. Algorithms
    --------------------------------------------------

    Definition:
    Step-by-step procedures used to solve problems or perform computations.

    --------------------------------------------------
    4.1 Sorting
    --------------------------------------------------

    Definition:
    Arranging data in a specific order (ascending/descending).

    --------------------------------------------------
    4.2 Searching
    --------------------------------------------------

    Definition:
    Finding an element within a data structure.

    --------------------------------------------------
    4.3 Greedy Algorithms
    --------------------------------------------------

    Definition:
    Algorithms that make the locally optimal choice at each step.

    --------------------------------------------------
    4.4 Dynamic Programming
    --------------------------------------------------

    Definition:
    An optimization technique that stores results of subproblems to avoid recomputation.

    --------------------------------------------------
    4.5 Backtracking
    --------------------------------------------------

    Definition:
    A method that tries all possible solutions and backtracks when a solution fails.

    --------------------------------------------------
    4.6 Bit Manipulation
    --------------------------------------------------

    Definition:
    Techniques that use binary representation of numbers to solve problems efficiently.

    --------------------------------------------------
    5. Problem-Solving & Practice
    --------------------------------------------------

    Definition:
    The process of applying concepts and patterns through practice to improve problem-solving skills.

    Includes:
    - LeetCode practice
    - Mock interviews
    - Timed coding

    --------------------------------------------------
    6. Best Practices
    --------------------------------------------------

    Definition:
    Guidelines to write efficient, readable, and optimized code.

    Includes:
    - Analyze before coding
    - Identify pattern first
    - Optimize step-by-step
    - Use correct data structure
    - Write clean code
    - Practice consistently
