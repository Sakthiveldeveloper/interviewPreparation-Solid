🧠 ⚡ Redis – Complete Understanding
🔹 1. What is Redis?
6

👉 Redis = In-memory key-value database

Stores data in RAM (not disk)
Extremely fast ⚡
Used mainly for caching
🧠 2. Why Redis?
Without Redis:
Every request → DB 😓 (slow)
With Redis:
First request → DB → store in Redis
Next request → Redis ⚡ (fast)
🧠 3. Basic Data Types
🔹 String (most used)
SET user:1 "Sakthi"
GET user:1
🔹 Hash (object-like)
HSET user:1 name "Sakthi" age 25
HGET user:1 name
🔹 List
LPUSH tasks "task1"
🔹 Set
SADD users "A" "B"

👉 Interview tip:

“Redis supports multiple data structures like strings, hashes, lists, and sets.”

🧠 4. Caching (Most Important 🔥)
🔹 Flow:
Check Redis
If data exists → return
Else → fetch from DB → store in Redis

👉 Called:

Cache Hit ✅
Cache Miss ❌
🧠 5. Expiry (TTL)
SET user:1 "Sakthi" EX 60

👉 Auto delete after 60 sec

💬 Interview:

“TTL helps keep cache fresh.”

🧠 6. Use Cases (VERY IMPORTANT)
🔥 Most Common:
API caching
Session storage
Rate limiting
Real-time analytics
Leaderboards
🧠 7. Redis vs SQL vs MongoDB
Feature	Redis	SQL	MongoDB
Storage	Memory	Disk	Disk
Speed	Very fast	Medium	Fast
Use	Cache	Structured	Flexible
