# 🍎 MacBook Air M5 - Development Setup Guide

## Phase 1 - Install Homebrew

### Install Homebrew

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

### Add Homebrew to PATH

```bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
```

### Verify

```bash
brew --version
```

# Phase 4 - GitHub SSH Authentication

## Generate SSH Key

```bash
ssh-keygen -t ed25519 -C "sakthivel24498@gmail.com"
```

Press **Enter** for all prompts.

---

## Start SSH Agent

```bash
eval "$(ssh-agent -s)"
```

---

## Add SSH Key

```bash
ssh-add --apple-use-keychain ~/.ssh/id_ed25519
```

---

## Copy Public Key

```bash
pbcopy < ~/.ssh/id_ed25519.pub
```

# Phase 7 - Install NVM

```bash

```

Create directory

```bash

```

---

## Configure nvm

```bash
echo 'export NVM_DIR="$HOME/.nvm"' >> ~/.zshrc

echo '[ -s "/opt/homebrew/opt/nvm/nvm.sh" ] && \. "/opt/homebrew/opt/nvm/nvm.sh"' >> ~/.zshrc

echo '[ -s "/opt/homebrew/opt/nvm/etc/bash_completion.d/nvm" ] && \. "/opt/homebrew/opt/nvm/etc/bash_completion.d/nvm"' >> ~/.zshrc
```

Reload

```bash
source ~/.zshrc
```

Verify

```bash
nvm --version
```

## One suggestion

Since I know you'll be setting up future office Macs as well, I'd go one step further and create a **single `mac-setup.sh` script**. You'd only need to run:

```bash
sh mac-setup.sh
```

and it would automatically:

* Install Homebrew
* Install Git
* Configure Git
* Install NVM
* Install Node
* Install pnpm
* Install VS Code
* Install Docker
* Verify all installations

That way, setting up a new Mac would take about **10–15 minutes** instead of manually repeating every step. I think it's well worth creating as your personal setup script.
